# 7. Cronograma y roles

El proyecto está planificado para desarrollarse durante **16 semanas**, desde el
levantamiento de requerimientos hasta la entrega final del ERP funcionando en la
nube.

## 7.1 Roles del equipo

| # | Rol |
|---|-----|
| 1 | Product Owner / Documentación |
| 2 | Arquitecto de Software / Tech Lead |
| 3 | Desarrollador Frontend / Diseñador UI-UX |
| 4 | Desarrollador Frontend / Diseñador UI-UX |
| 5 | Desarrollador Backend / Base de Datos y DevOps |
| 6 | Desarrollador Backend / Base de Datos y DevOps |

## 7.2 Matriz por semanas y fases

| Fase | Semanas | Actividades principales | Entregables | Responsable(s) |
|------|---------|-------------------------|-------------|----------------|
| **1. Planificación y Análisis** | 1–3 | Entrevistas con la autoescuela, levantamiento de requerimientos, análisis del problema y definición del alcance. | Transcripción y Matriz de Requerimientos | Product Owner y Arquitecto de Software |
| **2. Diseño del Sistema** | 4–6 | Modelado de procesos (BPMN AS-IS / TO-BE), arquitectura técnica, modelo Entidad-Relación y mockups en Figma. | Primera Defensa (Documentación PDF y Mockups) | Equipo completo |
| **3. Sprint 1 — Módulo Base** | 7–9 | Configuración del entorno, base de datos, autenticación y Módulo de Gestión de Estudiantes. | MVP 1 (CRUD Estudiantes) | Desarrolladores Frontend y Backend |
| **4. Sprint 2 — Core del Negocio** | 10–12 | Módulo de Instructores, Módulo de Vehículos y lógica de asignación/programación de clases. | MVP 2 (Gestión Académica) | Desarrolladores Frontend y Backend |
| **5. Sprint 3 — Módulo Financiero** | 13–14 | Módulo de Pagos, registro de abonos, cuentas por cobrar y generación de reportes/balances. | MVP 3 (Finanzas y Reportes) | Desarrolladores Frontend y Backend |
| **6. Despliegue y Pruebas** | 15 | Pruebas de integración, corrección de errores, carga de datos reales y despliegue en servidor cloud. | Sistema desplegado en la nube | Arquitecto de Software y Desarrolladores Backend |
| **7. Cierre y Presentación** | 16 | Pruebas finales de aceptación con la autoescuela, preparación de la presentación oral y defensa final. | Defensa Final (Sistema Operativo) | Equipo completo |
